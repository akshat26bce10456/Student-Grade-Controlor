 Project Description

 Grade calculator is a python based program made to calculate the grade of students.
 It also assign the topper of the class.In the project user has to enter marks between 0to 100 for respective subjects.
 The program uses some of the concepts of python like functions, conditional statments, user input, error handling and modules.
 
Features
 User has to input the marks.
 Marks should range between (0 to 100).
 This input make to validate the grade.
 Displays Pass or Fail .
 Handles invalid input.
 Uses a separate Python module for grade calculation.
 Grade Criteria
 Marks	Grade
 90–100	A+
 80–89	A
 70–79	B
 60–69	C
 50–59	D
 Below 50	F

Error Handling

Marks above 100.
Non-numeric input.
